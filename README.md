# foldbox-gallery

Contenu communautaire de l’app **Foldbox** (réalisations + pages légales).

## Liens utiles

- Catalogue : [`showcases.json`](./showcases.json)
- Les textes du catalogue (`gameTitle`, `description`, `folds[].label` et
  `folds[].note`) utilisent des objets `{ "fr": "...", "en": "..." }`.
- Politique de confidentialité :
  [https://cuizinierr.github.io/foldbox-gallery/privacy.html](https://cuizinierr.github.io/foldbox-gallery/privacy.html)
- Règles de la communauté :
  [https://cuizinierr.github.io/foldbox-gallery/community-guidelines.html](https://cuizinierr.github.io/foldbox-gallery/community-guidelines.html)
